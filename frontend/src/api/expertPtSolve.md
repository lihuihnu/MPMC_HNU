# 免登录 PR76 自定义模型计算

## 当前开发重点

软件不需要账号、注册、登录、OAuth/OIDC 或 IdP。当前增量优先完成实际计算流程，
不再以 Web identity 或部署平台为热力学工作的前置条件。

- C++ 负责 PR76 物性/逸度、初始相稳定性搜索、两相/三相分裂与最终相集合复核。
- 前端编辑数据，通过已有 typed client/本地 IPC 调用计算，不包含 EOS/闪蒸公式，
  不接触原生指针、注册表或进程凭据。
- 本增量使用已有 Electron 本地计算通道。普通 Web/Android 仍保留已有 PT Flash
  入口；没有新建登录页、公开原生服务端口或引入身份依赖。

## 实际使用

1. 打开桌面软件，进入 **PR76 Expert**；本地计算进程由程序连接，无需账号。
2. 在左侧填写模型标识、参数来源与组分。支持新增、删除、重排组分；填写摩尔质量
   [kg/mol]、Tc [K]、Pc [Pa]、偏心因子及每个无序组分对的显式 kij。缺失 kij
   不会被当成零。选择已提供的 preset，或在完整后端设置快照上修改 CUSTOM 设置。
3. 点击 **Create immutable model** 应用模型。每次应用创建新的不可变模型，
   不会原地修改正在计算的模型，也不会回退到预置示例流体。
4. 在右侧输入 P [Pa]、T [K]、按当前模型组分顺序排列的进料摩尔分数 z，点击
   **Compute PR76 flash**。初始值均为空，不填充猜测数据，不静默归一化进料。
5. 阅读已接受相数、各相摩尔相分率 beta、各相组分摩尔分数 x，以及可用的 Z、
   原生诊断与相数转移证据。应用的模型参数和来源仍可展开查看。

修改参数、kij、组分顺序或设置后，旧结果立即隐藏；先应用新模型，再计算。
应用新模型会重新建立空的温压/进料输入，避免新增/删除/重排组分后沿用错位的 z。
修改 P/T/z 也会清除旧结果。在途计算可以按既有后端期限完成，但迟到结果不能
覆盖当前输入或新模型。每个计算面板最多一个在途请求，不排队、不自动重试。

## 稳定性与结果语义

`ExpertOwnedModel.solve()` 始终绑定创建时的隐藏引用，输入为既有 `ModelSolveInput`，
输出保留完整 `FullPtResult`。它兼容共享客户端的完整消息与 renderer 的
`{outcome,result}` 包装，不通过预置 backend ID 再次选择流体。

`candidatePhaseSet` 存在或含三相，不代表该相集合已经被接受。只有原生 outcome
为 ACCEPTED 才显示“Accepted phase count”；INDETERMINATE/PHASE_SET_UNSTABLE 的
相数据放在明确标识的诊断候选区。没有根据 Z 推测油/气/水相标签。

PR76 capability 声明执行初始稳定性搜索和最终复核，但 `globalStabilityProven`
为 false 时不能称为全局稳定性证明。界面展示现有协议提供的 diagnostic 与
transitionReport；本增量**没有新增独立 TPD 分析接口、TPD 极小值或完整迭代残差历史**。

本地输入检查仅处理十进制/科学记数法、有限正温压、组分身份/顺序和单个摩尔分数
范围。归一化容差、适用范围、active support、求解门槛由原生模型判断。字段错误
使用已有 typed code/field，不解析或显示任意原生异常文本。

## 所有权与回归

编辑输入不是取消整个传输会话的理由：现有 typed client 取消语义可能使所有旧引用
失效。因此 `ExpertPtSolveGate` 只失效旧发布，不在键入时中断内部模型或隐式重建。
窗口/模型释放仍走既有生命周期；创建完成时原界面已卸载，则释放未交付模型。
旧模型释放失败不能被理解为新模型仍可继续使用；工作区阻止继续计算并保留诊断。

聚焦回归覆盖：动态组分对齐、空/非法输入、原样传递进料、单请求限制、迟到结果/错误、
卸载后创建资源清理、完整结果克隆与 hints/options 传递、已接受相与候选相分离。
UI/序列化测试使用明确的合成数据，不是物性验证。

实际 Electron model IPC 回归使用已有 C++ 导出的带来源参数/状态，经新输入构造函数和
opaque owner.solve 求解，并与真实 native-host 基线逐字段一致比较。原有 service 的
直接 C++ 一致性回归与独立科学参考保留；跨层 parity 本身不能替代独立科学验证。
CI 的真实执行结果记录在对应 PR，不把未执行或 skipped 的测试算作通过。

## 下一项数值工作

本增量不改 PR/TPD/split/max3 数值公式或容差。源码审计确认当前 PR76 backend
capability 对 `2→1` 仍声明 detection-only。后续应围绕相消失边界做定点数值审计：
验证能否通过 fresh 单相稳定性判定闭合该转移，而不是直接删掉小相或把未确定状态
升级为成功；保持已有独立参考、守恒/逸度门槛和 `2→3 / 3→3 / 3→2` 回归。

applicability/hints/result v1 的兼容约定不是禁止完善科学内核。未使用 identity 专用
代码的清理另做小范围依赖审计，不影响当前免登录计算路线。
