# CPA no-cold-reference association observable certificate audit

## Status

This document derives and validates a **test-only a-posteriori certificate** for

```text
MPMC_HNU/CPA/association-continuation-safety/v1
```

The certificate decides whether a warm association fixed-point candidate can be
accepted **without first running the current cold association solve at the same
density**.

Nothing in this slice enables continuation in production. The production
association equations, `1e-12` stopping tolerance, density scan, root solver,
stability solver, PT flash solver and failure semantics remain unchanged.

The completed audit establishes two separate facts:

1. a no-cold mathematical/engineering enclosure can conservatively bound the
   warm candidate on the fixed validation workload; and
2. the current **absolute-pressure form is too conservative to deliver a net
   performance benefit**, so it is not ready for production use.

## 1. Association fixed-point map

For site classes `a,b`, define

```text
w_b  = x_component(b) * multiplicity_b
A_ab = rho * w_b * Delta_ab >= 0.
```

`Delta_ab` is generated by the same production-double
`cpa_association_strength(...)` kernel used by the existing solver. It is not
recomputed in a different precision/model for the certificate.

The mass-action equation is

```text
F_a(X) = 1 / (1 + sum_b A_ab X_b)
X*     = F(X*).
```

The production damping changes the iteration path but not this fixed point.
For a converged warm candidate `Xhat`, the certificate freshly evaluates

```text
H(Xhat) = Xhat - F(Xhat).
```

No cold state enters this calculation.

### Uniqueness background

Xu, Brennecke and Stadtherr, *Reliable Computation of Phase Stability and
Equilibrium from the SAFT Equation of State*, Ind. Eng. Chem. Res. 41 (2002)
938-952, DOI `10.1021/ie0101801`, discuss this class of SAFT association
site-fraction equations and establish uniqueness of the point-valued solution in
`[0,1]`, then use interval-Newton expansion to enclose all feasible association
solutions.

That result supports treating the warm and cold iterations here as
approximations to the same physical association solution. The implementation
below still performs its own local numerical enclosure rather than relying on
that literature result as a substitute for computation.

## 2. Krawczyk-style local enclosure

Define

```text
H(X) = X - F(X).
```

Its Jacobian is

```text
J_ab(X) = delta_ab + A_ab / (1 + sum_c A_ac X_c)^2.
```

For a positive box

```text
B = [Xhat-r, Xhat+r],
```

all `A_ab` are nonnegative, so the Jacobian can be bounded directly. With
`l=Xhat-r`, `u=Xhat+r`:

```text
Dmin_a = 1 + sum_c A_ac l_c
Dmax_a = 1 + sum_c A_ac u_c

Jlow_ab  = delta_ab + A_ab / Dmax_a^2
Jhigh_ab = delta_ab + A_ab / Dmin_a^2.
```

The test implementation computes `B0 = J(Xhat)^-1` and uses

```text
M = abs(I - B0 Jmid) + abs(B0) Jrad.
```

The box is accepted only when

```text
abs(-B0 H(Xhat)) + M r < r
```

componentwise and every lower site-fraction bound remains positive. This yields

```text
|X*_a - Xhat_a| <= r_a.
```

The current implementation performs the enclosure algebra in `long double` and
uses explicit inflation. It is an engineering certificate, **not yet a formal
directed-rounding interval proof**. Cross-platform production enablement would
require an outward-rounded implementation or equivalent demonstrated numerical
conservatism.

## 3. Pressure certificate

At fixed `(T,rho,x)`, the physical SRK pressure is independent of the association
site fractions. Production uses

```text
P_assoc = -C_P * sum_a w_a (1-X_a)
C_P     = 0.5 * R*T*rho * (1 + rho*dln(g)/drho).
```

The analytic site-box contribution is therefore

```text
|Delta P| <= C_P * sum_a w_a r_a.
```

The initial implementation used only this term and was empirically too small at
some dense states. The cause was not a failed site enclosure: it was the
floating-point arithmetic of a large association-pressure term followed by
physical/association cancellation.

The current audit therefore adds a **candidate-local, no-cold arithmetic
allowance**. It evaluates the production double pressure expression and the same
expression from the same stored double inputs in `long double`, then includes the
observed arithmetic gap plus a numerical-inflation pad. The final pressure bound
is

```text
analytic site-box propagation + candidate-local pressure arithmetic allowance.
```

It must still satisfy the already frozen contract scale

```text
5e-6 Pa.
```

No threshold was relaxed to make the certificate pass.

## 4. `ln(phi)` certificate

At fixed target pressure, temperature, density and composition, the
association-dependent chemical potential is

```text
mu_assoc_i = sum_(a in i) m_a ln(X_a)
             - K_i * sum_a w_a (1-X_a)

K_i = (1.9/8) * rho * b_i * g.
```

For the certified box `l_a=Xhat_a-r_a`, `u_a=Xhat_a+r_a`, define

```text
L_a = max(ln(Xhat_a/l_a), ln(u_a/Xhat_a)).
```

The analytic association contribution is bounded by

```text
|Delta ln(phi_i)| <=
    sum_(a in i) m_a L_a
    + K_i * sum_a w_a r_a.
```

Two candidate-local arithmetic terms were also required by validation:

1. production-double `mu_assoc` versus the same stored-double expression in
   `long double`; and
2. the final production evaluation

```text
mu_cubic + mu_assoc - ln(Z)
```

versus the exact `long double` sum of those same stored double operands.

Both allowances use only the warm candidate and current `(p,T,rho,x,parameters)`.
They do not use a cold reference. The augmented component bound must remain
inside

```text
max |Delta ln(phi)| <= 1e-10.
```

## 5. Root-sign certificate

Observable closeness alone is not enough to preserve the density-root search.
For every scan state the audit separately checks whether the pressure interval

```text
[P_warm - E_P, P_warm + E_P]
```

lies wholly in one of the current production sign classes:

```text
residual > +pressure_tolerance
residual < -pressure_tolerance
|residual| <= pressure_tolerance.
```

If the interval crosses a sign boundary, the warm state is not root-safe and a
future implementation would have to use the current cold path.

This leaves the existing density locations, `scan_intervals`, sign logic,
bracketing, bisection, root merging and pressure tolerance unchanged.

## 6. Validation protocol and scope

The validation first runs the established 333.15 K methanol-water five-state
physical flash and records its **497 production root requests**. For each actual
request composition, the no-cold audit evaluates the normal 512-point monotone
root-scan lattice:

```text
root requests  = 497
scan states    = 497 * 512 = 254,464
seeded states  = 497 * 511 = 253,967
```

This certificate validation intentionally focuses on the normal scan lattice. It
does **not yet cover the additional bisection and accepted-root density
evaluations** that raise the complete performance-baseline count to 305,928.
There is no reason to extend the more expensive full replay until the present
pressure-certificate selectivity problem is solved.

For each seeded state:

1. the warm-only certificate is computed;
2. enclosure, pressure, `ln(phi)` and sign decisions are recorded;
3. the existing cold solve is then computed **for validation only**;
4. the observed warm/cold `X`, pressure and `ln(phi)` differences are checked
   against the combined independently computed warm/cold enclosures.

Cold values are never inputs to the warm certificate decision.

## 8. Performance consequence of the current certificate

For this 512-point scan audit:

```text
cold sweeps      = 10,517,712
warm sweeps      =  6,109,024
effective sweeps = 10,719,214
```

`effective_sweeps` conservatively charges every uncertified warm attempt for both
its attempted warm solve and the required current cold fallback. Therefore

```text
sweep_reduction_fraction = -0.019158349268358021
```

or about **1.92% more fixed-point work than the current cold path**.

This is the decisive result of the audit: the certificate is conservative on the
validation set, but its current absolute-pressure form rejects too many states to
preserve the 43.67% continuation opportunity found by the earlier cold-reference
continuity audit.

## 9. Scientific conclusion

A no-cold-reference association certificate has been derived and empirically
validated on the fixed scan workload:

- the site fixed-point enclosure succeeds for every seeded state;
- all empirical warm/cold differences are contained by the computed bounds;
- `ln(phi)` is not the dominant rejection source;
- root-sign classification is certifiable for every tested scan state;
- **absolute pressure certification is the dominant blocker**.

Therefore this version is **not production-ready** and must not be used to enable
continuation merely because it is mathematically conservative.

The key distinction is that the current pressure certificate bounds a warm
production value against an underlying mathematical fixed-point observable. For
root-search acceleration, the practically relevant quantity is the difference
between the warm production evaluation and the production evaluation associated
with the unique exact association solution. A future bound should exploit the
fact that large physical/association and floating-point terms are common rather
than paying their absolute roundoff magnitude independently.

## 10. Next audit boundary

The next step should be **difference-form pressure certification**, still
without production integration:

```text
bound fl(P(Xhat)) - fl(P(X*)) directly,
not |fl(P(Xhat)) - P_exact(X*)| as two independent absolute errors.
```

That derivation must:

- retain the frozen `5e-6 Pa` pressure scale;
- preserve current pressure-sign and root-tolerance semantics;
- account explicitly for double rounding in the linear association-pressure
  expression and final physical/association addition;
- use outward-rounded/directed interval arithmetic or an equivalently justified
  floating-point error bound;
- fall back whenever the interval can cross the current sign/tolerance boundary;
- be validated against the same cold reference only after the warm-only decision
  has been made.

No production association-continuation code should be written before that
pressure certificate is shown to recover a positive net sweep reduction.
