# SW92/corrected-original thermodynamics kernel

## Scope

This increment implements a **thermodynamics-only** Søreide–Whitson 1992 profile:

```text
SW92/corrected-original/PR76-base/NaCl-molality
```

The public thermodynamic state is

```text
p [Pa], T [K], x [component mole fractions],
NaCl molality [mol NaCl / kg H2O], SwPhaseFamily
```

with `SwPhaseFamily::{aqueous,nonaqueous}` selected explicitly **before** resolving the Peng–Robinson cubic roots. Family and root index are separate concepts. This increment does not perform TPD/stability search, two-phase splitting, three-phase flash, phase-count selection, phase labeling, sensitivity, frontend/service work, or physics coupling.

Salt is an external fixed-molality state variable in this profile. NaCl is not expanded into Na+/Cl- EOS components and no salt-inventory conservation problem is solved.

## Source and corrected-original convention

Primary source: I. Søreide and C. H. Whitson, *Peng-Robinson predictions for hydrocarbons, CO2, N2, and H2S with pure water and NaCl brine*, Fluid Phase Equilibria 77 (1992) 217-240, DOI `10.1016/0378-3812(92)85105-H`.

The implementation was transcribed against the user-supplied PDF whose SHA-256 is:

```text
cb5b1d5034d78d934e887449ce0c89692d43431835d1371da5606d95b2c6bf58
```

The PDF includes the authors' errata as its final page. `corrected-original` means that the corrected N2 Eq. (13) and corrected Table 2 constants are used, rather than the original misprints. No 2026 refreshed BIP fit is silently substituted.

Relevant source locations:

| Paper location | Implemented role |

| journal p.222, Eqs. (10a,b) | AQ/NA classical PR attraction mixing |
| journal p.222-223, Eqs. (11),(12), corrected Table 2 | hydrocarbon/water AQ BIP |
| journal p.226, corrected Eq. (13) | N2/water AQ BIP |

| journal p.231, Eq. (17) | H2S/water NA BIP |
| journal p.224, Table 3 | regression/reference component-property lineage used by tests |

The production model does not embed a component database. Parameter records remain explicit, ordered, sourced input data.

## Water alpha

For water, Eq. (9) is implemented exactly in the printed/corrected model form:

```text
sqrt(alpha_H2O) = 1
  + 0.4530 * [1 - Tr * (1 - 0.0103 * c_sw^1.1)]
  + 0.0034 * (Tr^-3 - 1)
Tr = T / Tc,H2O
```

`c_sw` is NaCl molality in `mol/kg H2O`, not a mole fraction, mass fraction, ppm value, or dimensionless salinity. Inputs require finite `T>0` and finite `c_sw>=0`. Optional declared T/p/molality bounds are enforced without clipping; absent bounds mean unknown validity.

Non-water components use the PR76 alpha expression and the PR76 printed coefficients `0.45724`, `0.07780`, `0.37464`, `1.54226`, `0.26992`. The gas constant convention is the repository's modern SI value `R=8.31446261815324 J/(mol K)`, which is a numerical convention rather than a constant taken from SW92.

## Phase-family BIPs

The model deliberately does not infer AQ/NA family from root size.

### Aqueous water-pair BIPs

Hydrocarbons use corrected Eq. (12):

```text
k_AQ = A0*(1 + alpha0*c)
     + A1*Tr_i*(1 + alpha1*c)
     + A2*Tr_i^2*(1 + alpha2*c)

A0 = 1.1120 - 1.7369*omega_i^-0.1
A1 = 1.1001 + 0.8360*omega_i
A2 = -0.15742 - 1.0988*omega_i
alpha0 = 0.017407
alpha1 = 0.033516
alpha2 = 0.011478
```

Hydrocarbon routing therefore requires `omega_i>0`. No component name parsing is used.

Corrected N2 Eq. (13):

```text
k_AQ = -1.70235*(1 + 0.025587*c^0.75)
     + 0.44338*(1 + 0.08126*c^0.75)*Tr_i
```

CO2 Eq. (14):

```text
k_AQ = -0.31092*(1 + 0.15587*c^0.7505)
     + 0.23580*(1 + 0.17837*c^0.979)*Tr_i
     - 21.2566*exp(-6.7222*Tr_i - c)
```

H2S Eq. (15):

```text
k_AQ = -0.20441 + 0.23426*Tr_i
```

### Non-aqueous water-pair BIPs

H2S uses Eq. (17):

```text
k_NA = 0.19031 - 0.05965*Tr_i
```

For hydrocarbon, N2, and CO2 water pairs, the corrected-original parameter contract requires an explicit sourced constant. Table 5 values can therefore be supplied without being hidden inside an ID-to-number switch. In particular the supplied paper prints C3 `0.5525` and n-C4 `0.5091`.

The paper later uses `0.5` for hydrocarbon/water binaries absent from Table 5. This implementation **does not silently apply that fallback**. A caller that intentionally adopts `0.5` must submit it as an explicit sourced/assumption record.

### Non-water/non-water BIPs

SW92 provides the special water-pair correlations, not a universal multicomponent gas/gas BIP database. If more than one selected non-water component is present, every selected non-water pair must therefore provide explicit sourced `aqueous_kij` and `nonaqueous_kij`. Missing values are rejected; neither zero nor equality between the two families is inferred.

## Mixing, roots, and fugacity coefficients

For the selected family, Eq. (10) is evaluated as

```text
a_mix = sum_i sum_j x_i x_j sqrt(a_i a_j) (1-k_ij^family)
b_mix = sum_i x_i b_i
```

The full composition must be finite, each `x_i` in `[0,1]`, and its sum within `64*epsilon` of one. The expression uses the submitted fractions and never normalizes or clips them.

The resulting dimensionless PR coefficients are

```text
A = a_mix p / (R T)^2
B = b_mix p / (R T)
```

The existing tested `pr76_roots` algebraic resolver is reused because SW92 retains the same Peng–Robinson cubic; this reuse is only a root-algorithm reuse and does not reuse PR76 parameter/model identity. Roots are returned in increasing Z and no root is called aqueous, non-aqueous, stable, liquid, or vapor.

For an explicitly selected root, `ln(phi_i)` is evaluated with the classical Peng–Robinson mixture fugacity expression using the selected family's row sums. The implementation uses exact `sqrt(2)` and a cancellation-aware logarithmic form. This is a candidate-property kernel, not an equilibrium calculation.

## Data contract

`Sw92ParameterSet` is independent of `PrParameterSet`. It reuses only generic component/provenance infrastructure.

Key invariants:

- exact model profile match; no bare `SW` alias or fallback;
- exactly one selected component is explicitly routed as `Sw92Species::water`;
- species routing is data, never inferred from component IDs/display names;
- every selected component has sourced Tc/Pc/omega;
- every selected non-water component has a water-pair record;
- H2S/Water NA must use Eq. (17); other supported water pairs use explicit sourced NA constants;
- all selected non-water/non-water pairs are complete for both families;
- dataset ID, revision, application declaration, units, conversions, and provenance remain owned by the snapshot.

The builder validates structure and metadata; it does not prove a source is scientifically correct. The correlations are empirical and their publication ranges must not be treated as global thermodynamic validity proofs.

## Numerical and verification contract

The first SW92 kernel is intentionally floating-point only. It does **not** claim AD derivatives. Adding derivatives later requires an explicit audit of fractional salinity powers at zero molality, root conditioning, and the intended fixed-molality versus conserved-salt coordinate.

Independent tests use Python standard-library `Decimal(80)` with no production imports. The reference independently evaluates Eq. (9), corrected Eqs. (12)-(15), Eq. (17), double-sum mixing, the original-Z PR cubic via Newton iteration, and the direct PR fugacity expression. Production uses a different shifted-root resolver/logarithmic algebra, so agreement cross-checks both formulas and implementation paths.
